 Site do Curso Técnico em Informática - ETEC Alberto Santos Dumont

 Sobre o Projeto
Este projeto consiste em um site institucional desenvolvido para apresentar o Curso Técnico em Informática da ETEC Alberto Santos Dumont, localizada em Guarujá/SP.
O objetivo do site é fornecer informações sobre o curso, sua história, estrutura curricular, certificações, áreas de atuação profissional e identidade visual, servindo como um portal informativo para estudantes, responsáveis e interessados na área de tecnologia.
 Funcionalidades
•  Página inicial com apresentação do curso.
•  Página "Sobre" com história e legado do curso.
•  Informações sobre a matriz curricular.
•  Descrição das disciplinas técnicas.
•  Certificações progressivas.
•  Informações sobre atuação profissional.
•  Layout responsivo e organizado.
•  Menu de navegação entre páginas.
•  Utilização de imagens e identidade visual própria.
 Tecnologias Utilizadas
